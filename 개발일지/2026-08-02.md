# 개발 일지 — 로그인·가이드 수정 & 팀 소개 페이지

**날짜:** 2026.8.2
**대상:** llm-frontend (React + TypeScript)
**요약:** 로그인·가이드 페이지를 다듬고, 팀 소개 페이지(`TeamPage`)와 팀원 데이터를 신설했다. 튜토리얼 조각과 랜딩 네비/푸터도 함께 손봤다.

*(8.1은 커밋 없음 — 건너뜀)*

---

## 1. 팀 소개 페이지 (`pages/TeamPage.tsx`, `features/team/members.ts`)

팀 구성원을 소개하는 페이지를 새로 만들었다. 팀원 정보를 `features/team/members.ts` 데이터로 분리하고, 화면은 그 데이터를 그려내는 방식.

- `pages/TeamPage.tsx` — 팀 소개 화면
- `features/team/members.ts` — 팀원 데이터
- `App.tsx` — 라우트 추가
- 사이드바 푸터(`SidebarFooter`)에서 팀 소개로 가는 진입점 정리

## 2. 로그인·가이드 페이지 수정

- `pages/LoginPage.tsx`, `pages/GuidePage.tsx` — 레이아웃·연출 보정
- `ui/components/landing/LandingNav.tsx`, `LandingFooter.tsx` — 네비/푸터 정리(팀 소개 링크 포함)
- `features/tutorials/parts.tsx`, `pages/TutorialPage.tsx` — 튜토리얼 조각 보강
- `ui/styles/global.css` — 관련 스타일

---

## 오늘의 회고

- 팀 소개도 데이터(`members.ts`)와 화면(`TeamPage`)을 분리하는 지금까지의 패턴을 그대로 따랐다. 가이드·튜토리얼·프로젝트·팀 — 콘텐츠성 화면은 전부 "데이터 파일 + 렌더 컴포넌트"로 통일되어 구조가 예측 가능해졌다.
- 랜딩 네비/푸터가 여러 화면(로그인·가이드·튜토리얼·팀)의 공통 진입점 역할을 하게 되면서, 여기만 고치면 전 화면의 이동 경로가 함께 정리된다.
