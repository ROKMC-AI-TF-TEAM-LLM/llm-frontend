# 개발 일지 — 프로젝트 기능 & 튜토리얼 페이지 신설

**날짜:** 2026.7.30
**대상:** llm-frontend (React + TypeScript)
**요약:** 대화를 프로젝트 단위로 묶는 프로젝트 기능을 새로 붙이고(사이드바 연동 포함), 튜토리얼 페이지를 신설했다. 기능 코드를 `features/` 폴더로 모으는 구조를 도입했다.

---

## 1. 프로젝트 기능 (`features/projects/`)

세션(대화)을 프로젝트로 묶는 기능을 추가했다. 기능 단위 코드를 한 폴더에 모으는 `features/` 구조를 처음 도입.

- `features/projects/` — `projectStore.ts`(상태), `mock.ts`(목업 데이터), `ui.tsx`, `icons.tsx`
- `pages/projects/ProjectPage.tsx` — 프로젝트 화면
- 사이드바 연동: `SidebarProjects.tsx`, `ProjectItem.tsx`, `ProjectChatItem.tsx` 신설 + `Sidebar`/`SidebarHeader`/`SidebarMenu` 연결
- `App.tsx` — 라우트 추가
- `utils/sessionTitle.ts` — 세션 제목 처리 유틸

> 아직 목업(`mock.ts`) 기반이다. 프로젝트 API가 붙으면 store의 데이터 소스만 교체하면 되도록 분리해뒀다.

## 2. 튜토리얼 페이지 (`features/tutorials/`, `pages/`)

사용 방법을 안내하는 튜토리얼 목록·상세 페이지를 만들었다.

- `features/tutorials/tutorials.ts`(콘텐츠 데이터), `parts.tsx`(조각 컴포넌트)
- `pages/TutorialsPage.tsx`(목록) / `pages/TutorialPage.tsx`(상세)
- 랜딩 네비에 진입점 추가

## 3. 로그인 페이지 배경 수정

로그인 화면 배경 연출을 다듬었다(`LoginPage`, `global.css`).

---

## 오늘의 회고

- `features/` 폴더 도입으로 "이 기능에 관련된 것들(상태·UI·데이터·아이콘)"이 한곳에 모였다. `pages/`·`hooks/`·`types/`로 흩어놓는 것보다 기능 단위 응집도가 높아 찾기 쉽다.
- 프로젝트·튜토리얼 둘 다 콘텐츠 데이터를 `.ts` 파일로 분리(mock/tutorials)해서, 화면 코드와 내용을 나누는 패턴을 유지했다. 28일 가이드(guideSections)와 같은 방향.
