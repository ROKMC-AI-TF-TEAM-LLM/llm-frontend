# 개발 일지 — 랜딩/가이드 페이지 디자인 개편

**날짜:** 2026.7.28
**대상:** llm-frontend (React + TypeScript)
**요약:** 로그인·가이드 화면을 랜딩 페이지 수준으로 개편했다. 재사용 가능한 랜딩 컴포넌트(네비·푸터·리빌 애니메이션·회전 단어·터미널 데모)를 `ui/components/landing/`으로 분리하고, 로그인 후 리다이렉트 유틸도 정리했다.

---

## 1. 랜딩 컴포넌트 분리 (`ui/components/landing/`)

로그인/가이드 화면에 흩어져 있던 요소들을 독립 컴포넌트로 뽑았다.

- `LandingNav.tsx` / `LandingFooter.tsx` — 상단 네비 / 하단 푸터
- `Reveal.tsx` — 스크롤 진입 시 나타나는 리빌 애니메이션 래퍼
- `RotatingWord.tsx` — 문구 일부가 돌아가며 바뀌는 효과
- `TerminalDemo.tsx` — 터미널 형태 데모 연출
- `NavPreview.tsx` — 네비 미리보기
- `guideSections.ts` — 가이드 섹션 데이터를 코드에서 분리

## 2. 가이드 페이지 디자인 수정

가이드 페이지의 레이아웃·간격·섹션 구성을 개편했다. 섹션 데이터를 `guideSections.ts`로 분리해 화면 코드와 콘텐츠를 나눴다.

## 3. 로그인 후 리다이렉트 정리 (`utils/postLoginRedirect.ts`)

로그인 성공 후 어디로 보낼지 결정하는 로직을 유틸로 뽑아 `AuthLayout`에서 사용. 화면 곳곳에 흩어질 분기를 한곳으로 모았다.

## 4. 팀 소개 진입점 손질

사이드바 푸터에서 팀 소개로 가는 아이콘/링크를 다듬었다.

---

## 오늘의 회고

- 랜딩 요소를 컴포넌트로 쪼개니 로그인과 가이드가 **같은 부품을 공유**하게 됐다. 한쪽을 고치면 다른 쪽도 자동으로 반영되어 톤이 어긋나지 않는다.
- 콘텐츠(guideSections)와 화면 코드를 분리한 게 특히 좋았다. 문구·순서를 바꿀 때 컴포넌트를 안 건드려도 된다.
